# 읽기 모드와 댓글 (gh-12)

문서 헤더에서 읽기 모드로 전환한다. 현재 모드를 명확히 표시하며 서식 도구를 숨기고, 본문·원문·속성·저장·히스토리 복원으로 문서를 변경하지 못하게 한다. 미저장 편집이 있으면 저장·버리기·취소를 선택해야 전환된다. 읽기 중 다른 문서를 열어도 읽기 모드를 유지한다.

의견 패널에서 댓글을 작성하고 조회한다. 댓글은 앱 데이터 디렉토리 `comments/<문서 식별자 SHA-256>.json`에 별도로 원자적 저장한다. 문서 원본은 수정하지 않는다. 원본 절대 경로를 댓글 식별자로 사용하므로 permalink나 다른 문서 속성 변경으로 댓글이 분리되지 않는다. 파일 자체를 다른 경로로 옮기면 이전 경로의 댓글 파일은 보존되며 자동 이전은 수행하지 않는다.

댓글은 UTF-8 텍스트로 저장하며 빈 댓글·10,000자를 넘는 입력을 거부한다. 손상된 댓글 JSON은 덮어쓰지 않고 오류를 표시한다. 댓글 삭제·편집·공유는 이 작업의 범위에 포함되지 않는다.

검증: Rust 14개, 에디터 14개, 데스크톱 10개 테스트 통과. 읽기 속성·서식 도구 비노출·체크박스 원상 유지·원문 붙여넣기 차단, 댓글 작성 전후 원문 동일, 댓글 재열기, 모드 전환의 저장/버리기/취소를 화면 통합 테스트로 확인했다. Rust 테스트는 별도 파일 영속성·문서 원본 불변·손상 데이터 보존·입력 검증을 확인한다. 타입 검사·웹 빌드·Rust check/fmt 통과.
