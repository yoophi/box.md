# 문서 카드 보기 (gh-9)

사이드 패널의 문서 카드 보기를 통해 작업 디렉토리 문서를 카드로 표시한다. 파일 이름, 상대 경로와 원본 front matter의 `summary`를 보여준다. 요약이 없으면 입력 안내를 표시하며 YAML/읽기 오류는 해당 카드에 표시한다. 카드 클릭은 기존 문서 열기와 미저장 변경 보호를 따른다.

파일 이름/경로 검색과 24개씩 페이지 이동을 제공한다. 현재 페이지의 요약만 최대 8개씩 읽어 큰 작업 디렉토리 전체 본문을 메모리에 적재하지 않는다. 요약 새로고침은 원본 파일을 다시 읽는다. 편집 화면으로 돌아가면 보관 중인 미저장 편집 내용을 유지한다.

검증: 에디터 15개/데스크톱 12개 테스트, 타입 검사와 웹 빌드 통과. HomePage에서 카드의 summary가 원문 값과 일치하고 카드 클릭으로 해당 문서를 여는 통합 흐름을 확인했다.
