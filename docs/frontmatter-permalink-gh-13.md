# Front matter permalink 설정 (gh-13)

문서 속성의 고정 링크 입력에 값을 입력하고 “문서에 적용”을 누른 뒤 문서를 저장한다. 저장된 Markdown의 YAML `permalink` 문자열을 정본으로 사용한다. 적용은 미저장 변경으로 표시되며 기존 저장·외부 변경 충돌·종료 보호를 따른다.

YAML AST를 통해 속성을 갱신하므로 주석, 중첩 속성, summary 등 다른 값은 유지한다. 본문과 front matter 닫는 구분자 이후의 공백은 그대로 보존한다. front matter가 없으면 생성하며 잘못된 YAML과 중복 키는 오류로 표시해 덮어쓰지 않는다. 일반 서식 편집은 전체 front matter envelope를 보존한다.

검증: 신규 생성, 문자열 타입, BOM/CRLF, 주석·중첩 속성·본문 보존, 비정상 YAML/중복 키/닫는 구분자 누락 거부를 테스트한다. 일반 파일 저장·재열기는 기존 문서 저장소 통합 테스트로 검증된다.

타입 검사·웹 빌드 및 에디터 13개/화면 통합 2개 테스트 통과. 화면 통합 테스트는 네이티브 파일 API만 대체해 전체 HomePage 입력→적용→저장→재열기와 히스토리 복원 흐름을 검증한다. Rust 파일 저장·Git 통합 테스트 12개도 선행 작업에서 통과했다.
