# 문서 Git 히스토리 (gh-8)

문서를 저장할 때 앱 데이터 디렉토리의 `history/<문서 절대 경로 SHA-256>` 저장소에 자동 커밋을 생성한다. 사용자 문서와 기존 Git 저장소의 index·브랜치·설정은 수정하지 않는다. Git 실행 파일이 필요하며 사용자 Git 이름·이메일 설정 없이 동작한다. hooks와 서명은 사용하지 않는다.

기존 파일을 처음 수정하면 수정 전 원문도 기록한다. 동일 내용의 연속 저장은 커밋을 추가하지 않는다. 문서별 저장소로 기록을 분리하며 앱 재실행 후에도 유지한다. 현재 경로 기준으로 기록을 관리하므로 파일 이름을 변경하면 새 기록으로 취급한다.

히스토리 버튼으로 저장 시각과 커밋 ID를 조회하고 원문을 확인한다. 복원은 편집 내용만 바꾸며 일반 저장을 통해 디스크와 새 기록에 반영한다. 미저장 변경이 있으면 복원을 확인한다. Git 기록 실패 시 파일 저장 결과를 유지하고 오류를 표시한다.

검증: 실제 Git 저장소의 버전 조회, Unicode/front matter 보존, 중복 방지, 문서 분리, 재시작 복원, 외부 변경 충돌 시 기록 방지, 히스토리 오류와 파일 저장 결과 구분을 Rust 테스트로 검증한다.

타입 검사·웹 빌드·Rust check/fmt 및 21개 테스트 통과. macOS debug 앱 번들 생성 성공. 네이티브 UI smoke는 CUA가 `cgWindowNotFound`를 반환해 실행하지 못했으며 화면 동작 검증은 후속 통합 검증에서 재시도한다.
