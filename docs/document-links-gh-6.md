# 문서간 연결 (gh-6)

문서 연결에서 다른 작업 디렉토리 문서를 선택하고 링크 추가를 누르면 본문 끝에 표준 Markdown 링크를 추가한다. 연결 대상에 permalink가 없으면 대상 front matter에 생성·저장한 뒤 링크를 만든다. 대상 본문·다른 속성은 유지하며 외부 변경 충돌은 기존 저장 계층이 차단한다. 현재 문서의 연결 내용은 일반 문서 저장으로 반영한다.

링크는 `boxmd://document?permalink=...` 형식으로 파일 이름에 의존하지 않는다. 서식 편집에서 문서 링크를 클릭하면 gh-7의 resolver와 미저장 보호를 통해 대상 문서를 연다. Markdown 원문에서는 링크를 직접 확인·편집할 수 있다. 기존 링크 입력에도 boxmd 스킴을 허용한다.

타입 검사·웹 빌드 통과. 에디터 14개/데스크톱 8개 테스트 통과: boxmd 링크의 Markdown 왕복, 대상 원문 보존·식별자 생성, 연결 저장, 클릭 시 미저장 보호 및 대상 열기를 검증했다. Rust 변경은 없으며 기존 저장 계층의 12개 테스트 결과를 유지한다.
