# 문서 한 줄 요약 (gh-10)

문서 속성의 “한 줄 요약”을 입력하고 문서에 적용한 뒤 저장한다. Markdown YAML front matter의 `summary` 문자열을 정본으로 사용하며 기존 permalink·중첩 속성·주석·본문을 보존한다. summary 없는 기존 문서는 빈 입력을 표시하고 정상적으로 열거나 편집할 수 있다. 빈 값 적용은 summary 속성을 제거한다. 읽기 모드에서는 요약을 변경할 수 없다.

다른 문자열 속성과 같은 AST 갱신·오류 처리·외부 변경 충돌 보호를 사용한다. 문서 재열기·재시작 시 원본 파일에서 값을 다시 읽으므로 별도 요약 저장소는 없다.

검증: 에디터 15개/데스크톱 11개 테스트, 타입 검사와 웹 빌드 통과. summary 문자열 타입·기존 permalink·본문 보존 및 summary 없는 문서의 입력→저장→재열기를 검증했다.
